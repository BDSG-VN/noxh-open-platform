# ADR-004: Versioned authoritative templates

Status: Historical Sprint 0 baseline, extended by [ADR 013](013-openai-dvc-legal-sources.md): source catalog and separately approved project guidance exist; filled-form rendering remains unavailable.

Form engine defines a metadata interface and explicitly rejects rendering. No official form or legal threshold is shipped. Future renderers require legal approval, version/effectivity checks, immutable original text and citizen confirmation.
